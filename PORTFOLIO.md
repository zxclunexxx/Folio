# Folio — мобильное рабочее пространство фрилансера

## Короткое описание для портфолио

Folio — гибридное Android-приложение для управления фриланс-проектами, задачами и поступлениями. Объединяет бюджеты, дедлайны, прогресс и историю оплат в спокойном адаптивном интерфейсе. Данные хранятся локально; предусмотрены резервные копии, светлая и тёмная темы. Основной стек: Java / Android WebView, JavaScript, HTML, CSS.

## Задача

Собрать понятный инструмент, в котором фрилансер видит, над чем работает, что нужно сделать сегодня и сколько денег действительно получил. Избежать перегруженного корпоративного интерфейса и обязательной регистрации.

## Решение

Четыре связанных раздела: обзор, проекты, задачи и доходы. В проекте видны задачи и оплаты; изменение задачи сразу меняет прогресс, а запись платежа — итог месяца. Ожидаемый бюджет и фактическая оплата разделены. Удаление проекта не уничтожает историю поступлений.

## Визуальный подход

Тёплый светлый фон, спокойный зелёный акцент, крупная редакционная типографика, повторяемые компоненты и иконки Font Awesome. Контент не зависит от внешних CDN. Тёмная тема и альбомная раскладка включены.

## Что показать за одну минуту

Открыть обзор и доход месяца → перейти в проекты → открыть проект → создать задачу и выполнить её → записать поступление → показать обновившийся доход → переключить тёмную тему → показать резервную копию.

Для демонстрации используйте помеченные демо-данные. Для личной работы очистите их в настройках.

## Границы кейса

Это демонстрационный проект с локальными данными, созданный с помощью AI-инструментов. Нет банковской интеграции, сервера, аккаунтов и синхронизации. Не стоит описывать его как опубликованный в магазине, полностью нативный Kotlin/Compose-продукт или релиз, протестированный на физических устройствах. Проверенные и непроверенные сценарии перечислены в README и отчётах.
